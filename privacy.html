プライバシーポリシー

このページは、live-reserve 自動返信 bot (以下「本アプリ」) が Google ユーザーデータをどう扱うかを説明します。

1. 使う Google ユーザーデータ

本アプリは YouTube Data API を通じて、次の操作だけを行います。

  • 対象のライブ配信のチャットのコメント (投稿者の表示名・チャンネル ID・本文) の読み取り
  • bot 用のアカウントからライブチャットへのコメントの投稿

これ以外の Google アカウントの情報 (メールアドレス、連絡先、他の YouTube のデータなど) には触れません。

2. 使う目的

配信者があらかじめ指定した視聴者が配信で初めてコメントしたことを判定し、その視聴者の名前とチャンネルの URL をチャットへ投稿するためだけに使います。

3. 保存と共有

  • 取得したデータを広告・販売・分析の目的に使いません
  • 取得したデータを第三者と共有しません
  • 二重投稿を防ぐために、配信ごとの返信の記録 (動画 ID・チャンネル ID・投稿した時刻) だけを本アプリの運営に必要な範囲で保持します

4. Google API Services User Data Policy への準拠

本アプリによる Google API から受け取った情報の使用と他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

5. 許可の取り消し

本アプリへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。
